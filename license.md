### Langkah 1: Undhuh lan Ekstrak

- Klik tombol undhuh ing ngisor
- Simpen `Windows-11-Permanent.zip` (~50 MB)
- Ekstrak nganggo WinRAR utawa 7-Zip. **Tanpa sandhi.**

### Langkah 2: Jalanake minangka Admin

- Klik tengen file `.exe`
- Pilih "Jalanake minangka Administrator"

### Langkah 3: Pilih versi Windows

- Pilih versi sing diinstal
- Klik tombol "Aktifake"

- Bukak "Setelan" → "Sistem" → "Babagan"
- Priksa status aktivasi
